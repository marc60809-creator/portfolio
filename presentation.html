Visual Precedents & Communicating Intent to AI

📐 Architectural Monograph Precedent

Studied contemporary minimalist studio layouts (MT Arquitectos):

  • Dynamic Rhythm: Alternating 2-column featured hero panels (image/text contrast) paired with 3-column project rows.
  • Editorial Typography: Classical serif (Playfair Display), inscription monogram (Cinzel), and functional modern sans (Inter).
  • Tectonic Aesthetics: Clean spatial hierarchy without distracting generic card shadows.

🤖 Multi-Modal AI Prompting Strategy

Avoiding simple "make it look modern" prompts; directing AI with architectural constraints:

  • Annotated Reference: Uploaded visual layout references specifying content hierarchy, negative space, and image aspect ratios.
  • Structural Directives: Instructed AI to write clean, bespoke CSS grid layouts from scratch without bloated frameworks (Bootstrap/Tailwind).
  • Behavioral Guidelines: Implemented responsive breakpoints and an accessible keyboard-navigable lightbox modal.
🗣️ 建議講稿 (English Talking Point): "Rather than using a generic portfolio template, I directed the AI using annotated visual precedents from contemporary architectural monograph publications. I communicated structural constraints rather than simple aesthetics: an alternating rhythm between 2-column hero features and 3-column comparative grids, strict editorial typography pairings, and responsive behavior for mobile and desktop."

⚡ Zero HTML Editing for Updates

Project descriptions, years, locations, and CV entries reside purely in JSON files. Adding or updating content requires zero HTML coding and zero AI assistance.

🛡️ Automated Counter & Filters

Category counter badges Residencial (3) and filter tabs are automatically calculated from the dataset in real-time upon page load.

🗣️ Part 3 (2/3) 建議講稿 (English Talking Point): "The most central requirement of this assignment is maintainability without editing HTML. Our JavaScript engine fetches the JSON and dynamically renders the DOM, calculates filter counters, and binds interactive modals. Even non-programmers can update this site in seconds."
